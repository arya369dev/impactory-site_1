# IMPACTORY — Arya Patole
Responsive cinematic portfolio prototype.

## Preview
Open index.html in a browser, or serve the folder with `python -m http.server 8000` and open http://localhost:8000.

## Before launch
1. Replace the example contact email in index.html with your real email.
2. Replace concept cards with genuine projects, verified links, and real case studies.
3. Add your real domain as canonical URL, sitemap.xml location, Open Graph absolute image URL, and schema `url` fields after domain confirmation.
4. Confirm which reference videos are intended; only the IMPACTORY intro video was available in this build.
5. The portrait is rendered as a layered, interactive 3D-style card, not a true rigged 3D human model. Supply a GLB/GLTF model for genuine 3D orbit/animation.
6. Test accessibility, mobile performance, and social previews on the deployed domain.
